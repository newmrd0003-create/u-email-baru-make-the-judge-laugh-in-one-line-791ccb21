# Make the Judge Laugh in One Line

Write a single one-liner (1–200 characters) that makes the judge laugh. Entries are judged pairwise — the funniest line wins.

## Entry

> My gym membership and I are in a toxic relationship — I pay $30 a month, it texts me 'we miss you,' and neither of us has seen the other since January.

## How to run

```bash
python3 main.py
```

This writes `entry.txt` to the directory given by `MAKEFUN_OUTPUT_DIR` (fallback `/output`). It never writes to the current working directory.
